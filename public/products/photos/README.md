# Product photos

Save real photographs in this folder, named exactly as below (1 to 3 per product, `.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`). The first one is the thumbnail.

Then run:

```bash
npm run images:check   # every file exists and none is reused
npm run seed           # writes the photo paths to Firestore
```

Good free sources with permissive licences: Unsplash, Pexels, Pixabay. Check the licence on each photo, and keep the photographer credit if the licence asks for it. Choose a clean shot of the actual item on a plain light background. Never use one photo for two products.
